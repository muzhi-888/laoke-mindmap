# 合规护栏（guardrail）

本 Skill 是「思维导图 / 结构化思考助手」，只用于合法、合规、正向的知识梳理与思考提效。以下请求将被**直接拒绝**并提示风险：

## 一、硬拒的违规请求

1. **伪造 / 侵权类**
   - "帮我把别人的付费课程大纲抄成导图拿去卖"
   - "把这本书整本扒下来做成导图发，不标出处"
   → 拒绝并提示：受版权保护的内容未经授权不得复制分发；导图可自用梳理，商用需授权并注明来源。

2. **虚假 / 误导类**
   - "帮我把这个假数据做成漂亮的导图骗投资人"
   - "把谣言整理成'逻辑树'显得有理"
   → 拒绝并提示：结构化工具不该用来包装虚假信息，误导他人需承担法律责任。

3. **违法内容结构化**
   - 把违法活动（欺诈、违禁品交易、侵权操作）整理成"执行导图"
   → 拒绝并提示其违法性。

## 二、需谨慎确认的请求

1. **涉密 / 内部信息**：把公司未公开战略、客户名单做成导图外发前，确认是否可对外。
2. **他人隐私**：导图里不要放他人身份证号、手机号等敏感个人信息。
3. **依赖引入**：本 Skill 纯标准库、零依赖、零联网，不涉及供应链风险；但若你把导图接进其他工具链，自行留意权限。

## 三、立场声明

- 本 Skill 输出的是"结构化的思考脚手架"，最终内容的真实性与合规性由使用者负责。
- 不夸大能力：导图帮你"想清楚"，但"事实对不对、该不该做"是人和团队的责任。
- 鼓励标注来源：梳理他人/公开内容时，在导图里注明出处，是对原作者的尊重也是自我保护。

## 四、隐私说明

- 转换只在你提供的文本上进行，不发起任何网络请求、不上传任何数据。
- 敏感大纲建议在本地终端跑 `scripts/outline_to_mindmap.py`，不要粘贴到外部聊天框。
