# 常见导图类型与选法

思维导图是个大框，往里装不同的"结构"就变成不同图。本 Skill 默认产出"放射状层级树"，但你知道还有哪些兄弟图，才能选对武器。

---

## 一、逻辑树（Logic Tree）—— 本 Skill 的主力

结构：一个问题在根，拆成互斥的子问题，再拆。
用途：拆解复杂问题、做根因分析、搭方案框架。
本 Skill 产出的就是这种。最通用。

```
中心问题
  原因A
    子原因A1
  原因B
```

---

## 二、鱼骨图（Fishbone / 石川馨图）

结构：结果在右（鱼头），大骨是"人/机/料/法/环"等维度，小骨是具体原因。
用途：质量复盘、找问题的归类原因（4M1E 法）。
和逻辑树区别：鱼骨强调"按固定维度归类原因"，逻辑树强调"逐层下钻"。
什么时候换鱼骨：当你要的是"按维度归因"而不是"自由下钻"时。

---

## 三、时间线（Timeline）

结构：从左到右按时间排。
用途：项目排期、历史事件、流程步骤。
本 Skill 不适合直接画时间线（它是网状的）。但你可以把"时间线"当作导图的一个分支：中心→阶段1→阶段2→阶段3。真要纯时间线，用专门的 timeline 工具。

---

## 四、矩阵（Matrix / 2x2）

结构：二维坐标，四个象限。
用途：优先级（重要×紧急）、定位（自己×对手）、评估（成本×价值）。
什么时候换矩阵：当你要做"两两对比 / 定位"时，矩阵比导图直观十倍。
经典： Eisenhower 矩阵（重要×紧急）、BCG 矩阵（增速×份额）。

---

## 五、金字塔（Pyramid）

结构：结论在最顶，下面三层论据支撑，每层论据再支撑。
用途：汇报、论证、写方案（结论先行）。
和逻辑树区别：金字塔强调"自上而下论证"，树强调"自下而上拆解"。常配合用：先用树拆解，再收成金字塔结论。

---

## 六、概念图（Concept Map）

结构：节点 + 带标签的连线（A 导致 B、A 属于 B）。
用途：表达关系而非层级（因果、依赖）。
导图只能表达"包含"，概念图能表达"因为/依赖/相似"。关系复杂时用概念图。

---

## 七、怎么选（决策表）

| 你要的 | 用 |
|--------|----|
| 一个主题发散出多维度、还要细分 | 逻辑树（本 Skill） |
| 按固定维度归原因 | 鱼骨图 |
| 先后顺序 / 排期 | 时间线 |
| 两两对比 / 定位 | 矩阵 |
| 结论先行论证 | 金字塔 |
| 复杂关系（因果/依赖） | 概念图 |

---

## 八、可以混用

实战里常组合：用**逻辑树**搭骨架 → 某一支用**矩阵**做对比 → 顶上收一句**金字塔**结论 → 排期那支抽出来做**时间线**。本 Skill 负责"树"这块，其余类型在导出的基础上手绘或换工具即可。
