# laoke-mindmap · 思维导图结构化助手

> 局内人·老K · 专注实体老板与开发者用 AI 落地实战

通用思维导图结构化助手：把一份有层级的大纲（Markdown 标题 / 缩进列表 / 编号列表）解析成层级树，直接产出三种可分发产物——**Mermaid 代码**（贴进笔记即渲染）、**嵌套 Markdown 列表**（当文章骨架）、**自包含 HTML 导图**（双击能看、可折叠、零依赖）。配套一套 MECE 分层与"什么图用什么"的方法论。

## 包含内容

- `SKILL.md`：完整结构化方法论与用法（中心/分支/叶子、MECE、选型、转化规则、输出规范）
- `references/`：五份领域知识（核心结构、MECE 分层、导图类型选型、大纲转导图规则、输出格式规范）
- `scripts/outline_to_mindmap.py`：纯标准库大纲转导图脚本（Mermaid / Markdown / HTML 三种输出）
- `hooks/guardrail.md`：合规护栏（硬拒侵权 / 伪造 / 虚假内容类请求）

## 快速开始

```bash
# 转换并写出三种产物文件
python scripts/outline_to_mindmap.py 输入.md --out all --write
```

输入示例：

```markdown
# 产品上线计划
## 研发
- 后端接口
  - 鉴权
  - 限流
- 前端页面
## 运营
1. 预热海报
2. 社群推送
## 风险
- 服务器容量
  - 压测
  - 扩容预案
```

## 适用场景

- 读书 / 听课做结构化笔记
- 方案 / 文章打骨架（导图 → 大纲 → 成文）
- 项目计划拆解（叶子挂负责人/时间变看板）
- 故障复盘归因
- 头脑风暴收束
